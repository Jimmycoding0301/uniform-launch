# 设计计划

## 自审

frontend-design 要求先写计划，再删掉「换一个项目也会这么做」的部分。删掉的有：中点拼接的状态串、列表和刻度的等宽小字、按钮后的勾、标题逐字上浮。近黑底和单一金色是本说明定的，不改。差异放在阶梯、同价矩形和读数窗。

ui-ux-pro-max 检索摘要：

- `crypto token auction dark minimal --design-system --density 7`：瑞士风、密度 7 可用。它给出的紫色强调、Orbitron 和霓虹不采用，和单一金色、Geist 冲突。
- `step chart threshold line --domain chart`：结果是仪表、时间折线和流式面积图，并建议红黄绿。和需求阶梯冲突，不采用。阶梯用实线、虚线区分价内价外，文字标「价内」「边际」「价外」。
- `form input label helper error --domain ux`：标签必须可见，错误要写明怎么改，失败后保留输入。已按这个做。

## 色值

见 `web/src/tokens.css`。组件不再写十六进制。错误不用红色，边框改金色，行首用空心方块。

## 字号

桌面 56、48、24、20、16、14、12。手机把 56 和 48 换成 36。品牌主名用字重 400。字重 300 在截图环境的中文回落上会发虚，不用。

## 间距

4 的倍数。左栏 400px，栏间距 40px。读数窗 56px。为了让 1440×900 的出价单落在视口内，帮助行间距用 4px，比说明里的 8px 更紧。

## 曲线

按容器像素画。同价矩形用方案乙，平涂 `--accent-a12`。方案甲的斜线排线和台阶、保留价虚线抢在同一条窄带里，260px 高的手机图上更花。对比图在 `qa/prototypes/rect.png`。价内台阶金色，价外台阶灰色。不画左侧纵轴线，不用模糊滤镜，清算点不循环呼吸。

## 原型结论

- 字重。`qa/prototypes/weight.png`。56px 下字重 300 比 400 更细，这台机器没有 300 的字重文件，浏览器会把笔画仿细，横画发虚。用 400。
- 同价矩形。`qa/prototypes/rect.png`。平涂是一块安静的面积。6px 斜线贴着保留价虚线和「保留价」几个字，窄带里数不清。用平涂。
- 读数窗。`qa/prototypes/window.png`。2px 底线和页面 64px 网格连成一条，看不出哪里能点。1px 整框把读数关在窗里。用整框。

## 曲线高度

右栏是一列：上面是曲线，下面是参数和出价。曲线固定 320px，不再跟着出价多少被拉高或被压成 0。32 笔出价在曲线下面滚动，表头吸顶。手机上曲线仍是 260px，并且占满内容宽。

## 帮助行

帮助行间距从 4px 改回 8px。腾出来的高度来自「编号怎么填」那一行：它是没有重置过的段落，上下各有大约 14px 的浏览器默认外边距。收成上 8px、下 0 之后，帮助行变高的部分被抵消。1440×900 上主按钮上沿仍是 796，下沿 844，左栏下沿 884。没有靠压帮助行来塞进第一屏。

## 控件依据

读数窗仿仪表窗。拨档仿两档开关。阶段尺是刻度尺，不能点。主按钮是实体按键。列表是撮合簿，左侧竖条区分价内和边际。回执是交割单。测试网地址是铭牌。

## 根因

8004 那 77px 空白是表单的 `padding-bottom: 64px`：按钮改成 fixed 之后，这一截仍留在帮助行和风险句之间。

手机图表被压扁，是因为绘图区高度写成 104px，viewBox 仍按 260 缩放，12px 刻度变成大约 5px。按钮已经固定，图高回到 260px，viewBox 跟容器像素一致。

## 和参照并排

截图在 `qa/r14/ref-uniswap.png`、`ref-megaeth.png`、`ref-linear.png`，接单页在 `qa/r14/after-open-1440.png`。

- 标题字重。Uniswap 和 Linear 的大标题都是常规字重，靠字号拉开。我们的「同价发射」是 56px、字重 400。对齐了。字重 300 在文泉驿上发虚，不用。
- 灰阶。Linear 的副标题几乎溶进底色，读不清。我们留了三档：`#F5F5F5`、`#C8C8CE`、`#9A9AA2`，次级文字对底色 11.81:1。比 Linear 的副标题更可读，这是故意的。
- 分隔线。Linear 的导航下沿是一条很淡的线。我们的列表线是 8% 白，区块线是 14% 白。同一档。
- 留白。三个参照的首页都是营销首屏，大半是空的。拍卖页是柜台，左栏 400px 把出价单放满，空的部分留给曲线。不把营销页的大留白搬过来。
- 不拿的。Uniswap 当天首页是浅底加粉色按钮和色块，不拿。MegaETH 当天首页是插画和饼干条，不是细网格。细网格、大面积留黑、细字重大标题按开工说明拿，不照这张战役页重做。
