# 为什么是同价

这组数字是模拟，参数见 `script/compare.mjs`。不是实测市场数据。

出价和本机分叉彩排相同，按出价顺序：20 BNB 最高价 0.0001，再 20 BNB 最高价 0.0001，再 1 BNB 最高价 0.00002。保留价 0.00001。同价清算结果是清算价 0.00008，入池 40 BNB。第三笔低于清算价，不成交。

对照曲线是常数乘积。虚拟储备按这个口径取：起点价格等于保留价，把同价入池的 40 BNB 全部买完时，终点价格等于同价清算价。报价储备约 21.88 BNB，代币储备约 218.8 万枚。另一种口径是把三笔预算一共 41 BNB 都拿去定储备，终点到不了清算价。两种都算了，推荐总募资相同的那一种，因为两边卖出的钱一样多。

| | 第一笔实付单价 | 最后一笔实付单价 | 单价比 | 价差 |
| --- | --- | --- | --- | --- |
| 同价 | 0.00008 | 0.00008 | 1 | 0 |
| 曲线，总募资相同 | 0.00001914 | 0.00005414 | 2.8284 | 0.000035 BNB/枚 |
| 曲线，按 41 BNB 定储备 | 0.00001891 | 0.00005266 | 2.7838 | 0.00003374 BNB/枚 |

同一区块里谁先谁后，不影响同价的清算价。一个身份只能出一笔。测试网的 Agent ID 是替身，任何地址调用领取就有余额；ERC-8004 测试网注册对所有人开放。防女巫要等主网接上币安 Agent ID 真合约才成立。测试网只演示规则，没有防住女巫。
