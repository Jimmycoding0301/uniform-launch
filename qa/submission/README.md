# 六幕演示验收

这组六张 1440×900 截图来自同一次浏览器演示。页面读取本机 Anvil 上的三场拍卖。公开测试网发射的进度另见[链上证据](../../docs/e2e-evidence.md)。

| 幕 | 屏幕上可以核对的内容 |
| --- | --- |
| [1 · 接单](scene-1.png) | 清算价 0.00002 BNB/枚。9 笔共提交 15.7 BNB。按保留价售完需要 5 BNB，本轮预计入池 10 BNB。 |
| [2 · 填单](scene-2.png) | 预算、限价和复制按钮保持清晰，周围面板降低对比度。底栏上方可见最后一笔出价和手动核对入口。 |
| [3 · 模拟](scene-3.png) | 在现有订单簿上模拟新增 1 BNB、最高价 0.00003 的委托，预计成交 50,000 枚，实际支出预计为 1 BNB。 |
| [4 · 发射](scene-4.png) | 500,000 枚同价成交，40 BNB 入池。左侧领取按钮紧接回执，右侧显示池与 Vault 税款读数。 |
| [5 · 退款](scene-5.png) | 3 笔合计 3 BNB，低于约 4.34 BNB 的最低入池额，缺口约 1.34 BNB。实际入池为零，三个地址均可领取全额退款。 |
| [6 · 对照](scene-6.png) | 同一组出价下，首尾成交单价比为 1.00。示例常数乘积曲线的模拟值为 1.7789。 |

在[需求曲线局部图](demand-curve.png)中，每个节点对应一个最高限价档位，横坐标是达到该档限价的累计预算。曲线表示档位之间的趋势。清算点对应 11 BNB 过线预算。按 0.00002 BNB/枚售出 500,000 枚时，预计入池 10 BNB。

运行 `bash script/demo.sh` 后打开终端打印的演示地址。点击幕号或使用左右方向键切换。用 `npm --prefix web test` 检查标注、配色、六幕切换、移动端触控尺寸及底栏遮挡。

还在独立本机分叉打开了测试网场次页面。复制 4.45 BNB 的出价指令后，页面自动匹配区块 144915598 中的发送地址、限价和金额，显示「出价已核对」。[分叉交易记录](../../deployments/bsc-testnet-budget-fork.json)收录了该笔出价。币安 App 的签名需要在真实测试网上另行验证。
